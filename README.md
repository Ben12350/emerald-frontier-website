# 翡翠战境官网

《我的世界》Java 1.8—26.3 服务器官网，使用原生 HTML、CSS 和 JavaScript 构建。

## 页面功能

- 响应式桌面与手机布局
- 原创体素竞技场视觉和粒子动画
- 一键复制服务器地址
- PVP 邀请流程、经济、领地与服务器指令介绍
- 自动更新服务器在线状态和在线人数

## GitHub Pages

推送到 `main` 分支后，`.github/workflows/pages.yml` 会自动部署静态页面。

## 文件

- `index.html`：页面结构
- `style.css`：完整视觉样式
- `app.js`：状态刷新、复制地址、粒子和滚动动画
